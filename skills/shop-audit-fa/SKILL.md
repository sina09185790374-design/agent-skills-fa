# آدیت یک‌صفحه‌ای پیج / مغازه

## ورودی
- هندل پیج یا نام و نوع کسب‌وکار
- هر داده قابل مشاهده: تعداد فالوور، نظم انتشار، بایو، هایلایت‌ها، راه‌های تماس، ساعت کاری

## مراحل
1. **وضعیت فعلی (۳ خط):** پیج/مغازه الان کجاست؟ (فعالیت، نظم، اولین برداشت مشتری)
2. **۳ نقطه قوت:** چیزهایی که همین حالا خوب کار می‌کند — صادقانه، بدون چاپلوسی.
3. **۳ نشتی مشتری:** جاهایی که مشتری از دست می‌رود (بایوی نامشخص، نبود راه تماس سریع، انتشار نامنظم، پاسخ‌گویی کند، نداشتن قیمت/نمونه‌کار).
4. **۳ اقدام فوری:** برای هر نشتی یک اقدام مشخص و ارزان که این هفته قابل انجام است.
5. **جمع‌بندی یک‌خطی:** «اگر فقط یک کار بکنید: …»

## قوانین
- حداکثر یک صفحه؛ هر بخش کوتاه و عدددار.
- عددی را که نداری حدس نزن — بنویس «قابل مشاهده نیست».
- لحن: مشاور دلسوز، نه فروشنده فشارآور. آدیت باید به‌تنهایی هم برای صاحب کسب‌وکار مفید باشد.
