# پاسخ قیمت و پیش‌فاکتور فارسی

## ورودی
- خدمت یا محصول و قیمت دقیق آن (از کاربر یا لیست قیمت کسب‌وکار)
- زمان تحویل/انجام
- شرایط پرداخت (نقدی، بیعانه و…) — اگر گفته نشد، بنویس «پرداخت هنگام تحویل»

## مراحل
1. **پاسخ کوتاه اول:** اول قیمت را شفاف بگو، بدون مقدمه‌چینی طولانی. مشتری قیمت پرسیده؛ احترام یعنی جواب مستقیم.
2. **ارزش کنار قیمت:** یک خط که این قیمت شامل چه چیزهایی می‌شود (گارانتی، پشتیبانی، اقلام همراه).
3. **پیش‌فاکتور متنی:** جدول ساده زیر را پر کن.
4. **قدم بعدی مشخص:** یک اقدام واحد برای بستن فروش (رزرو، ارسال آدرس، پرداخت بیعانه) + مهلت اعتبار پیشنهاد (پیش‌فرض: ۳ روز).

## قوانین
- هیچ قیمتی را حدس نزن یا تخفیف خودسرانه نده؛ اگر قیمت ورودی نیست، جای آن بنویس «<قیمت>» و از کاربر بخواه.
- همه مبالغ با واحد «تومان» و جداکننده هزارگان.
- لحن: مطمئن و شفاف؛ از «قیمت‌ها شناوره» و ابهام پرهیز کن.

## قالب خروجی
```
سلام 👋 <خدمت> برای شما <قیمت> تومان می‌شه و شامل <موارد همراه> هست.

🧾 پیش‌فاکتور
• خدمت/کالا: …
• مبلغ: … تومان
• زمان تحویل: …
• شرایط پرداخت: …
• اعتبار پیشنهاد: تا ۳ روز

برای نهایی‌کردن فقط کافیه <اقدام بعدی> ✅
```
